---
name: claude-retain-memory-summary
description: Mostrar resumen de memoria comprimida (recent + archive)
---

Muestra el resumen de la memoria comprimida — archivos recent.md y archive.md que se cargan automáticamente al iniciar sesión.

Ejecuta el comando:

```bash
# Desde la carpeta del plugin — siempre funciona:
./bin/claude-retain-memory-summary.ps1    # PowerShell (Windows)
./bin/claude-retain-memory-summary         # Bash (Linux/Mac)
```
