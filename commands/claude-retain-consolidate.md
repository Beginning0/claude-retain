---
name: claude-retain-consolidate
description: Consolidar diarios de sesión en resúmenes semanales
---

Consolida los archivos de sesión individuales en resúmenes semanales más compactos.

Ejecuta el comando:

```bash
# Desde la carpeta del plugin — siempre funciona:
./bin/claude-retain-consolidate.ps1    # PowerShell (Windows)
./bin/claude-retain-consolidate         # Bash (Linux/Mac)
```

Esto combina múltiples archivos de sesión en un resumen semanal, ahorrando espacio y tokens.
